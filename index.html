PROJECT 01

CHITTRBOX

Real-time chat application containerized and deployed on Kubernetes with automated CI/CD.

🐳 Docker☸️ Kubernetes🤖 Jenkins🟢 Nginx🔐 JWT⚡ Socket.io
View on GitHub ↗
01 — Problem
What This Project Solves

Building a real-time communication platform requires handling persistent WebSocket connections, user authentication, and scalable deployment. Chittrbox addresses the challenge of deploying a full-stack MERN chat application in a containerized, production-ready Kubernetes environment with automated CI/CD pipelines.

04 — Implementation
How It Was Built

The application was built using the MERN stack with JWT-based authentication for secure user sessions and Socket.io for real-time bidirectional communication. The entire application was containerized using Docker, with separate containers for the frontend, backend, and database services.

Nginx was configured as a reverse proxy to handle incoming traffic and route requests to the appropriate services. Kubernetes deployment manifests were created for scalable orchestration, and Jenkins pipelines automated the build, test and deployment process.

PROJECT 03

DEVSECOPS PLATFORM

Containerized full-stack application with security-focused Docker workflows using Docker Scout and Docker AI.

⚛️ React🦫 Go🐘 PostgreSQL🐳 Docker☸️ Kubernetes🔍 Docker Scout
01 — Problem
What This Project Solves

Container security is often overlooked during development. This project tackles the challenge of building a full-stack application with security-first Docker practices, leveraging Docker Scout for vulnerability scanning and Docker AI for intelligent container optimization, alongside multi-stage builds for minimal attack surface.

04 — Implementation
How It Was Built

The application features a React frontend communicating with a Go backend API, persisting data in PostgreSQL. Docker Compose orchestrates the multi-service architecture locally, while multi-stage Docker builds minimize image sizes and reduce the attack surface.

Docker Scout was integrated to scan container images for known vulnerabilities, and Docker AI was used to suggest optimizations for Dockerfiles and container configurations. The application is deployed on Kubernetes for production scalability.
